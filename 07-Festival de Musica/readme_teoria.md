# Mixins

Tambien ayudara a que el codigo HTML sea semanticamente mejor.

# ¿Como se crean ?

```
@mixin nombre-mixin{}
```

# ¿como se usan?

```
@include nombre-mixin
```

# Consideraciones

* Pueden tomar parametros como as funciones.
* SASS soporta tambien la creacion de funciones con @function pero su uso es un poco diferente a los mixins
