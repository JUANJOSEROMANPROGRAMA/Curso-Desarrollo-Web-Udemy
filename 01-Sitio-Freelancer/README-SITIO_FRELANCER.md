# Portafolio Freelancer - Diseño y Desarrollo Web

Este es un proyecto de una página web estática (Landing Page) desarrollada desde cero. El objetivo principal de este proyecto es poner en práctica fundamentos de desarrollo web front-end, creando un portafolio profesional para ofrecer servicios de diseño y desarrollo web.

## 🛠️ Tecnologías y Conceptos Aplicados

El proyecto fue construido utilizando únicamente tecnologí as base de la web, aplicando buenas prácticas de desarrollo:

### HTML5

* **Maquetación Semántica:** Estructuración del documento utilizando etiquetas semánticas como `<header>`, `<nav>`, `<main>`, `<section>` y `<footer>` para mejorar la accesibilidad y el SEO.
* **Formularios:** Implementación de un formulario de contacto estructurado y accesible haciendo uso de `<fieldset>`, `<legend>`, `<label>` y diferentes tipos de `<input>` (text, tel, email).
* **Iconografía SVG:** Uso de iconos vectoriales insertados directamente en el código (Tabler Icons) para evitar dependencias externas y mejorar el rendimiento de carga.

### CSS3

* **Normalize.css:** Integración de un archivo de normalización para asegurar que los estilos se rendericen de manera consistente en los distintos navegadores.
* **Fuentes Externas:** Conexión e importación de la tipografía "Krub" a través de Google Fonts utilizando `<link rel="preconnect">` para optimizar la carga.
* **Variables Nativas (Custom Properties):** Declaración de una paleta de colores global en el pseudo-selector `:root` para un código más limpio y fácil de mantener.
* **Manejo de Medidas (REM):** Configuración técnica ajustando el `font-size` del `html` al `62.5%`. Esto permite utilizar la unidad relativa `rem` de forma más intuitiva (donde `1rem` = `10px`).
* **Selectores:** Uso adecuado de selectores de clase e id para la manipulación de los estilos de la página.
* Estilo de escritura: Escritura de estilos css mediante modulos.
* Flexbox: Aplicacion de flexbox en la pagina para definir la direccion de elementos como la navegacion.

## 🚀 Estructura del Proyecto

El sitio cuenta con las siguientes secciones:

1. **Cabecera (Header):** Título principal y presentación.
2. **Navegación (Nav):** Enlaces a las distintas partes de la página.
3. **Perfil:** Breve descripción y ubicación.
4. **Servicios:** Listado de servicios ofrecidos (Diseño Web, Aplicaciones Web, E-Commerce).
5. **Contacto:** Formulario para recolección de datos de clientes potenciales.

## ⚙️ Cómo ejecutar el proyecto

Este proyecto no requiere de ningún entorno de ejecución complejo (como Node.js o servidores de bases de datos).

1. Clona este repositorio en tu máquina local o descarga los archivos.
2. Asegúrate de conservar la estructura de carpetas (el archivo `index.html` en la raíz y la carpeta `/Css` con `normalize.css` y `style.css`).
3. Abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Edge, Safari).
